## Launch an EC2 instance

### 📝 Task

Launch an nginx EC2 instance into any private isolated subnet created in the first lab.

### 🔎 Hints

- [What is EC2?](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/concepts.html)
- [EC2 CDK documentation](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.aws_ec2-readme.html)
- [Amazon Machine Images](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/AMIs.html)
- You can build this on top of the first lab's code

### 🗺  Step-by-Step Guide

1. Open
   ```bash
   workshop/workshop_stack.py
   ```

1. Assign the VPC to a variable
   ```python
   vpc = ec2.Vpc(
       self,
       "WorkshopVPC",
       max_azs=2,
       ...
   ```
1. Now launch a t2.micro instance with the Amazon Machine Image (AMI)
   `bitnami-nginx-1.23.3-22-r21-linux-debian-11-x86_64-hvm-ebs-nami` in an isolated subnet:
   ```python
   nginx_instance = ec2.Instance(
       self,
       "NginxInstance",
       instance_type=ec2.InstanceType("t2.micro"),
       machine_image=ec2.MachineImage().lookup(
           name="bitnami-nginx-1.23.3-22-r21-linux-debian-11-x86_64-hvm-ebs-nami",  # noqa: E501
       ),
       vpc=vpc,
       vpc_subnets=ec2.SubnetSelection(
           subnet_type=ec2.SubnetType.PRIVATE_ISOLATED,
       ),
   )
   ```

1. Deploy the project via
   ```bash
   npx cdk deploy
   ```

## Using a Load Balancer

### 📝 Task
Allow the web server to be reached from the internet.

### 🔎 Hints
- [Application Load Balancer (ALB)](https://docs.aws.amazon.com/elasticloadbalancing/latest/application/introduction.html)
- [CDK ALB](https://docs.aws.amazon.com/cdk/api/v2/python/aws_cdk.aws_elasticloadbalancingv2/README.html)
- [CDK ALB Targets](https://docs.aws.amazon.com/cdk/api/v2/python/aws_cdk.aws_elasticloadbalancingv2_targets.html)

### 🗺 Step-by-Step Guide
1. Open
   ```bash
   workshop/workshop_stack.py
   ```

1. Instantiate an internet facing load balancer:
   ```python
   alb = elbv2.ApplicationLoadBalancer(
       self,
       "WorkshopALB",
       vpc=vpc,
       internet_facing=True,
   )
   ```

1. And create a listener:
   ```python
   listener = alb.add_listener(
       "WorkshopListener",
       port=80,
       open=True,
   )
   ```

1. Now we need to add a target, where the traffic from the listener should go:
   ```python
   nginx_target = targets.InstanceTarget(
       nginx_instance,
       port=80,
   )
   ```
   and then register it to the listener:
   ```python
   listener.add_targets(
       "WorkshopTarget",
       port=80,
       targets=[nginx_target],
   )
   ```

1. You can deploy now. Then go to the [load balancers in the EC2 console](
   https://eu-west-1.console.aws.amazon.com/ec2/home?#LoadBalancers:) and have a
   look at what you deployed. Here you can also find the load balancer's DNS name.

## Autoscaling

### 📝 Task

Use an Autoscaling Group (ASG) for creating the instance(s).

### 🔎 Hints
- [EC2 Autoscaling](https://docs.aws.amazon.com/autoscaling/ec2/userguide/what-is-amazon-ec2-auto-scaling.html)
- [CDK Autoscaling](https://docs.aws.amazon.com/cdk/api/v2/docs/aws-cdk-lib.aws_autoscaling.AutoScalingGroup.html#allowalloutbound)

### 🗺 Step-by-Step Guide
1. Open
   ```bash
   workshop/workshop_stack.py
   ```

1. Replace the Instance with an Autoscaling Group:
   ```python
   nginx_autscaling_group = autoscaling.AutoScalingGroup(
       self,
       "WorkshopASG",
       vpc=vpc,
       vpc_subnets=ec2.SubnetSelection(
           subnet_type=ec2.SubnetType.PRIVATE_ISOLATED,
       ),
       allow_all_outbound=False,
       instance_type=ec2.InstanceType("t2.micro"),
       machine_image=ec2.MachineImage().lookup(
           name="bitnami-nginx-1.23.3-22-r21-linux-debian-11-x86_64-hvm-ebs-nami",  # noqa: E501
       ),
       min_capacity=1,
       max_capacity=2,
   )
   ```
1. Replace the target group with the following:
   ```python
   nginx_target = targets.InstanceTarget(
      nginx_instance,
      port=80,
   )
   listener.add_targets(
      "WorkshopTarget",
      port=80,
      targets=[nginx_target],
   )
   ```

1. Deploy your changes via
   ```bash
   npx cdk deploy
   ```
